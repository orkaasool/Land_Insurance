# Land_Insurance
CoreProtect Addon to Optimize Rollback

Customized Plugin For SUSOG SMP

"/insurance stamp" Select Rollback Center

"Drop" to reset Center

"Use" To Confirm Rollback

Must be installed with CoreProtect v23.1+
-----------------------------------------------------------
Land Insurance is an addon based on CoreProtect that allows any player (with customizable permission) to select a center of rollback with a “Selector” item; after selection player will be given an item ROLLBACK and tagged with an attribute describing the time of recording and the position (including dimension) of selected center; Dropping the item allows player to reselect; Any attempt of using rollback as a destructive action will be prohibited by autodetection; certain blocks (diamond, netherite, heavy core, conduit, etc) will not be restored to prohibit duplication; Entities except dropped item will be restored; Certain redstone component may suffer update related issue since the restoration is equivalent to /setblock function
Detailed Commands to be find on https://docs.coreprotect.net/commands/
